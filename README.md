A fast drop-in replacement for make.fun's csv-reader 1.0.0. It reads broken CSV files exactly as csv-reader does — same columns, rows, and errors on every case — but several times faster, using bulk string slices instead of character-by-character concatenation.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`), answers each with `run` from `solve.js`, and writes `/output/answers.json`.
